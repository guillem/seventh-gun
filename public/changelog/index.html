Changelog

One entry per release, newest first. The repository's commit history is the complete record; this page covers what a player would notice.

0.1.0 current build

The first playable release. Everything below is in the build at seventhgun.com now.

  • Seeded maze runs: 88×88 cells, 12–14 spine rooms plus loot spurs, 55–75 enemies on Normal, deterministic from a short seed.
  • Seven guns with distinct behaviour, from the hitscan pistol to the void cannon that breaks the arena seal.
  • Seven authored campaign maps with progression, persistent guns between maps and health reset on entry.
  • Three difficulty levels that scale the whole economy, not just health.
  • Multiplayer arena: generated 96×96 map, up to ten players, on Cloudflare Workers or a self-hosted Node server.
  • Map editor with a compact SGMAP.v1 share code.
  • Map log of past runs per browser, seed links and copy-link sharing.
  • Touch controls for phones and tablets.
  • MIT-licensed source, Docker image, and an npx-able package.

Known gaps: human pacing validation of the 20–30 minute target is still pending, and there is no gamepad support.

Unreleased

Site work rather than game work: a crawl policy, a sitemap, structured data, link previews, these text pages, and a read-only JSON API so agents can read a seed's layout instead of guessing at a canvas. See /api/.
