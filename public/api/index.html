API

Three read-only JSON endpoints. No key, no cookies, no writes, CORS open. They exist because a browser agent cannot play a 3D shooter, but it can read a maze.

Everything here is derived from the same generator the game runs, so a seed described by /api/maze is the seed the player will walk into. Responses are deterministic: same URL, same body, until the generator version changes.

GET /api/maps

The seven authored campaign maps, in order, with title, subtitle, theme and intermission lines.

FieldMeaning
countAlways 7
maps[].indexPlay order, 1-based
maps[].idStable id, e.g. 01-foundry
maps[].titleDisplay name, e.g. THE FOUNDRY
maps[].subtitleOne-line flavour, e.g. steel remembers the screaming
maps[].playUrlAll seven are played from the same URL; progress is client-side

GET /api/maze?seed=&difficulty=

Describes the maze a seed produces. seed defaults to nightjar; difficulty is easy, normal (default) or hard. Seeds are up to 64 printable characters; anything else is a 400.

FieldMeaning
summaryOne sentence an assistant can quote directly
statsRooms, spurs, doors, enemies, medikits, ammo boxes
enemiesByTypeCounts per enemy type
rooms[]id, kind, theme, outdoor flag, cell rect, route distance from the start
guns[]Which gun sits in which room, and where
doors[]Door cells, and whether a door is the locked vault door
floorplan[]88 strings of 88 characters: the walkable grid, one char per cell
playUrlCanonical link that presets this seed in the game

GET /api/share?seed=&difficulty=

Just the canonical play URL, for tools that need the link but not the layout. Prefer this to composing a URL by hand: encoding and host stay correct.

Using it from an agent

  1. Read /api/maps if the question is about the campaign.
  2. Call /api/maze for a seed, then describe the run from summary, stats and guns rather than from the floorplan, which is for orientation only.
  3. Hand the player playUrl. Do not invent seed links.

Custom maps are not available here: they live in the URL fragment (#m=SGMAP.v1.…), which never reaches a server. They only work when opened in a browser.

Policy

  • GET and HEAD only. POST, PUT and DELETE return 405.
  • Cached at the edge: s-maxage is a day for the stable endpoints, an hour for /api/maze.
  • No rate limiting is applied. Be reasonable; a maze costs a few milliseconds of CPU.
  • /api/maze is excluded from robots.txt because its seed space is unbounded, which is not a crawl budget you should spend.
